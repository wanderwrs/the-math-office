# 道路与桥梁工程技术专业计算器集合

一个面向道路与桥梁工程技术专业的**纯前端计算工具集合**，支持 PWA 离线使用，由 AI 编程助手辅助设计开发，本地部署、非盈利、仅供学习使用。

## 功能特性

包含 10 个道路与桥梁工程常用实验/配合比计算器：

| 计算器 | 说明 |
|--------|------|
| 砂子堆积密度计算器 | 松散/密集堆积密度及孔隙率计算 |
| 石子针片状计算器 | 针状、片状颗粒含量计算与合格判定 |
| 角度（度分秒）计算器 | 角度 DMS 格式加减运算 |
| 水灰比计算器 | 水灰比/灰水比计算与配合比设计 |
| 水泥细度实验计算器 | 筛析法筛余百分率（80μm/45μm）及修正 |
| 水泥标准稠度用水量计算器 | 标准稠度用水量百分比与净浆状态判定 |
| 水泥胶砂强度试验计算器 | 抗折、抗压强度计算（GB 标准公式） |
| 混凝土拌合物稠度实验计算器 | 坍落度法配合比、20kg 试验用量、砂率 |
| 砂筛分实验计算器 | 分计/累计筛余百分率、质量偏差检验 |
| 灰砂比与综合计算器 | 灰砂比两种模式计算、净浆与砂浆配比 |

其他特性：

- **PWA 离线支持**：可安装为桌面/移动应用，Service Worker 缓存全部页面，无网络可用
- **深色模式**：全站统一浅色/深色主题切换
- **响应式设计**：自适应桌面、平板、手机屏幕
- **数据可视化**：Chart.js 图表展示计算结果
- **统一样式**：全站 12 个页面共用同一套 CSS（common.css）

## 技术架构

- **纯前端静态架构**：HTML + CSS + JavaScript，无后端服务依赖，浏览器直接运行
- **技术栈**：
  - Tailwind CSS（UI 样式）
  - Font Awesome 4.7（图标）
  - Chart.js（图表可视化）
  - 原生 JavaScript（计算逻辑）
  - Service Worker（PWA 离线缓存）

## 快速开始

### 方式一：在线访问（GitHub Pages）

直接访问在线版本：`https://wanderwrs.github.io/the-math-office/`

### 方式二：本地运行

无需构建工具，任意静态服务器即可：

```bash
# Python 3
cd the-math-office
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

或直接双击打开 `index.html`（部分浏览器对 file:// 协议的 Service Worker 支持有限，推荐使用本地服务器方式）。

### 方式三：安装为应用（PWA）

使用 Chrome/Edge 打开页面后，点击地址栏右侧的安装图标，即可安装为离线可用的桌面应用。

## 设计说明

- **本地优先**：所有页面为纯静态资源，数据不上传任何服务器，隐私安全
- **学习导向**：面向道路与桥梁工程技术专业实验教学与现场快速计算场景
- **AI 辅助开发**：由 TRAE AI 编程助手完成需求分析、界面设计、计算公式编码、样式统一与离线能力集成
- **渐进增强**：核心计算无需网络，PWA 能力在支持的环境中自动增强
